Approach 1: Simple recurrence

Given two strings s and t, return the number of distinct subsequences of s which equals t.

    Input: s = "rabbbit", t = "rabbit"
    Output: 3

Note: Use two pointers i, j to compare characters in s with characters in t. If they match, we have two cases: consider the match, or drop the match in the hope that there will be a match in future. If they don't match, just increment i.

if $s[i] == t[j]$

$f(i, j) = f(i + 1, j) + f(i + 1, j + 1)$

else

$f(i, j) = f(i + 1, j)$
